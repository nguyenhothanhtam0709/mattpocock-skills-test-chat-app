# Glossary Map

## Contexts

- [Chat](./GLOSSARY.md): the product's domain, where Users exchange Messages in Conversations
- [Factory](./docs/factory/GLOSSARY.md): the agent pipeline's process terms, how Tickets become pull requests and how documents are kept correct

## Relationships

- **Factory → Chat**: the Factory produces changes to Chat's code and docs
- **No shared terms**: the contexts share no term. Chat terms are never used for process concepts, and Factory terms are never used for product concepts
